# IRIS · Integrated Remote Intelligence for Spaceflight

> 🚀 **Try IRIS live: [iris-deep-thinkers.onrender.com](https://iris-deep-thinkers.onrender.com/app/visao/Main.html)**

Vision monitor for astronauts (SANS), by team Deep Thinkers.

NASA Space Apps Challenge 2026, Maputo. Challenge: *Create Health Monitoring Software for Astronauts on Space Missions*.

A tablet app that detects the earliest signs of SANS (Spaceflight-Associated Neuro-ocular Syndrome) between formal exams, compares each astronaut against their own normal, and tells them what to do. Cycle: **test → comparison → traffic light → action**.

Rules for anyone writing code (people and Claude): see [`CLAUDE.md`](CLAUDE.md).

## How to run the simulator

```bash
pip install numpy matplotlib
python3 simulador/simulador.py
```

The files in `dados/` and `app/dados.js` are overwritten. The seed is fixed, so the results are reproducible.

## Contract between the pieces (do not change without telling the team)

**`dados/astronautas_simulados.csv`**: one row per astronaut per test day.

`astronauta_id, perfil, dia, oct_um, amsler_zonas, amsler_centro, acuidade_linha, melhora_com_oculos, perg_focar, perg_contraste, perg_dor_cabeca, perg_visao_dupla`

- `perfil`: `populacao`, `demo_verde` (DEMO_A), `demo_amarelo` (DEMO_B), `demo_vermelho` (DEMO_C)
- `oct_um`: empty on days without an OCT (OCT on days 0, 10, 30, 60, 90, 120, 150; day 0 = pre-flight)
- `amsler_zonas`: zones with distorted lines, separated by `;` (3×3 grid, zones 0–8, center = 4)
- `acuidade_linha`: smallest line read (higher = better; baseline = 10)

**`dados/faixas.json`**: for each day (0–180), the `p10`, `p50`, `p90`, `p97` percentiles of the change in retinal thickness (Δ%), the `subida_rapida` (rapid rise) limits for each interval between OCTs, `s_min_um`, and the `z_score` formula.

## Traffic-light rules (provisional until validated by the health team)

Baseline = the astronaut's first OCT. `Δ% = (x − baseline) / baseline × 100`.

| Signal | Green | Yellow | Red |
|---|---|---|---|
| OCT | Δ% ≤ P90(day) | P90 < Δ% ≤ P97 | Δ% > P97, or yellow + rapid rise |
| Amsler | no new zone | new zone outside the center | new zone in the center |
| Acuity | same as baseline | worse by ≥ 1 line | does not improve with backup glasses |

Final color = the worst of the three. OCT reference: the `cor_oct()` function in `simulador/simulador.py`.

Works with new astronauts: the range is expressed as a percentage change, and each person establishes their own baseline on their first test.

## Data and sources

- Calibration: Macias et al. 2020, JAMA Ophthalmology (362 µm pre-flight, ~+10% by day 150; severe case 401 → 613 µm by day 84)
- Evidence for the pitch (not used in the calculation): NASA OSDR, RR-9 mission, mouse tonometry (OSD-583)
- Individual astronaut eye data is not public; the demo uses simulated astronauts calibrated against published figures.
