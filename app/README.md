# app/ (Marllon and Chandy)

> **The final interface is in `visao/`** (Marllon's screens wired to the backend, see `visao/README.md`). `camara/teste_visao.html` is the backend test screen.

Offline web app for any device with a browser (phone, tablet, PC). 5 screens: body dashboard, quick test (Amsler, acuity, 4 questions), guided OCT, chart with traffic light, actions and a package for the flight surgeon.

Load in this order in `index.html` (no fetch, no CDN):
```html
<script src="dados.js"></script>          <!-- generated by the simulator: window.FAIXAS, window.ASTRONAUTAS -->
<script src="../motor/regras.js"></script> <!-- window.REGRAS -->
<script src="../motor/motor.js"></script>  <!-- window.Motor -->
```
Example: `Motor.avaliar(Motor.registosDe("DEMO_B", ASTRONAUTAS), 90, FAIXAS, REGRAS)` → color, reasons, and text. See `../docs/EDILSON.md`, section 4.

## Camera module: distance to the screen (`camara/`)

The camera **does not** perform the Amsler test (the test measures what the person sees). It is only used to make sure acuity and Amsler are always done at the same distance (30–45 cm), so results are comparable from day to day.

- `camara/distancia.js`: `Distancia.iniciar(video, {minCm, maxCm, aoMudar})`, `Distancia.calibrar(40)`, `Distancia.parar()`
- `aoMudar(r)` receives `{estado: "ok"|"perto"|"longe"|"sem_cara"|"indisponivel", cm, mensagem}` (ok / too close / too far / no face / unavailable)
- Distance = K / (distance between the eyes in pixels). Without calibration, ±15%. With the "I'm at 40 cm" button, K becomes exact and is saved on the device.
- `camara/vendor/mediapipe/`: Google's face detector (Apache-2.0), copied locally so it works **without internet**. Do not edit.
- Distance only: `camara/teste_distancia.html`.
- **Full quick test: `camara/teste_visao.html` + `camara/teste_visao.js`.** Profile (picked from the list) → distance (camera, 1.5 s stable between 30 and 45 cm, or "Continue without camera") → Amsler right eye → Amsler left eye → near reading (10 lines, Sloan letters, 4 options, 2 attempts per line) → backup glasses (only if reading got worse than the baseline) → 4 questions → traffic light from `Motor.avaliar`.
- Tests are stored on the device (`localStorage`, key `dt_registos`), in the same format as `ASTRONAUTAS`, with extra fields: `amsler_od`, `amsler_oe`, `acuidade_com_oculos`, `distancia_cm`, `sem_camara`. Each astronaut's first test is the baseline.
- Letter size: 8 mm on line 1 down to ~1 mm on line 10 (PROVISIONAL, to be validated by the health team). Amsler grid: ~10 cm.
- Tested end to end (automated Chrome, no internet): baseline gives green; distorted center + loss of 2 lines with no improvement from glasses gives red; distorted side zone gives yellow.
- **Open with `abrir_app.command` (Mac) or `abrir_app.bat` (Windows)**, not by double-clicking the HTML. Under `file://` the camera is `indisponivel` (unavailable) and the app shows "Hold the screen about 40 cm away".
- Tested in automated Chrome, with a simulated camera and internet blocked: loads offline, rejects objects that are not faces, and fails cleanly under `file://`.

- **No OCT entry for real astronauts** (team decision, Nov 14): the quick test uses only Amsler, near reading, and 4 questions. OCT stays with the simulated demo astronauts.
